# 🌐 LinguaAI - Language Translation Tool

A simple AI-powered language translation tool built using Python, Streamlit, and Google Gemini.

## 🚀 Features

- Translate text between multiple languages
- 15 supported languages
- Swap source and target languages
- Character counter
- Clear text option
- Copy translated text
- Text-to-speech
- Download translation as a text file
- Clean and responsive Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
